When you try to activate a promo code, you might see messages such as: "The coupon cannot be activated. Please check and try again." “Coupon not found.” “Coupon was already used.” “Coupon doesn’t exist. Please check for typos and try again.” These usually happen for one or more of the following reasons: The code has already been activated by you: Or, if the code had a limited number of uses, other players may have reached the maximum activations allowed.
